# Autobiography of a Yogi — Chapter 2 Lyric Reader

Karaoke reader for the 1946 public-domain text of *Mother’s Death and the Amulet*.

- Tap play: live male voice, gold lyric highlight
- Optional: attach `yogi-ch02-grok.mp3` (Grok Atlas take) and lyrics lock to that recording
- Mobile-first, single `index.html`

## Grok Build

Open Grok → **Build**. Paste:

> Import https://github.com/joannaBareo1/yogi-lyric-reader and publish this as a live grok.me app. Keep index.html as the only page. Do not rewrite the lyric engine. Add a share cover: dark temple gold, om mark, title “Chapter 2 · Mother’s Death and the Amulet”.

Then publish to anyone with the link.
